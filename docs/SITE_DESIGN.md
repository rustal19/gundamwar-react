# サイト全体設計(情報設計・運用方針・未決事項)

機能仕様([PORTAL_SPEC.md](PORTAL_SPEC.md))の上位にあたる、サイト全体の設計と
運用方針。**§4 の未決事項リストは下位モデル(次セッション)が適切なタイミングで
ユーザーに確認する**こと。

## 1. 情報設計(決定済み)

### ページマップ(最終形)

| パス | ページ | 状態 |
|---|---|---|
| `/` | **ポータルトップ**(下記) | T8 で新設。既存 Home.js(空)を置き換え |
| `/search` | カード検索(フォーム+結果) | 既存。SearchForm の表示場所を `/` から移す |
| `/deck` | デッキ構築 | 既存 |
| `/decks`, `/decks/:id` | 公開デッキ一覧・詳細 | T2 済み |
| `/tournaments`, `/tournaments/:id` | 大会一覧・詳細 | T4 |
| `/tournaments/new`, `/tournaments/:id/manage` | 主催者コンソール | T5 |
| `/profile` | プロフィール(ニックネーム) | T6 |
| `/admin/users` | 権限管理+モデレーション | T3 済み、T10 で拡張 |
| `/terms`, `/privacy` | 利用規約・プライバシーポリシー | T9 |

### ポータルトップ(`/`)の構成(上から)

1. サイトタイトル+短い紹介文
2. **開催予定・進行中の大会**(最大5件、`/tournaments` への「もっと見る」)
3. **新着公開デッキ**(最大5件、`/decks` への「もっと見る」)
4. カード検索・デッキ構築への大きめの導線カード
- お知らせ(ニュース)機能は**作らない**。大会一覧で代用(決定済み)。

### ナビゲーション(ヘッダー)

`検索(/search) | 公開デッキ | 大会 | デッキ構築(β版)` + 右端にログイン/プロフィール。
ロゴ/サイト名クリックで `/`(トップ)へ。モバイルはハンバーガー内で同じ並び。
`mobileLayout` クエリの引き継ぎ(buildPathWithForcedMobileLayout)を全リンクで維持する。

### サイト名

現状「Gundam War Database」。ポータル名に変えるかは未決(§4)。

## 2. 運用方針(決定済み)

- **モデレーション**: admin による強制対応のみ(公開デッキの強制非公開+ニックネームの
  強制リセット)。通報フォームは作らない。API は PORTAL_SPEC §3 admin を参照。
- **利用規約・プライバシーポリシー**: 静的ページとして用意する。ドラフトは実装タスク
  (T9)内で作成し、**公開前にユーザーの確認を必ず取る**。内容: 個人運営の非商用サイト、
  Google ログインで取得する情報(メール・名前・アバター)と用途、Cookie/セッション、
  アクセス解析、公開コンテンツ(デッキ・ニックネーム・大会成績)の扱い、削除依頼窓口、免責。
- **結果報告は主催者のみ**、**ニックネーム必須**(実名非公開)は PORTAL_SPEC 参照。

## 3. 技術方針(決定済み・確認済み)

- SPA(CRA)のまま進める。SEO/OGP の制約(公開デッキのシェアカード等)は§4の将来課題。
- ペアリング表示のリアルタイム更新はしない(手動リロードで開始)。
- モックファースト: 全機能を localStorage モックで先に完成→バックエンド接続
  ([BACKEND_DESIGN.md](BACKEND_DESIGN.md))。
