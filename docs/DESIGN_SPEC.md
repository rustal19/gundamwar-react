デザイン・表示調整フェーズの**要件確定版**。作業地図は [DESIGN_HANDOFF.md](DESIGN_HANDOFF.md)、

## 1. 決定事項サマリ

| 項目 | 決定 |
|---|---|
| トーン | **ライト&クリーン**(白基調・清潔・データベースらしさ) |
| テーマ初期値 | **ジオン系**(ジオングリーン×モノアイピンク)。プレビュー確認済み |
| テーマ変更性 | 全色を意味ベースCSS変数に集約し、**変数ブロック差し替えだけで**テーマ変更可能にする(必須要件) |
| 密度 | **ハイブリッド** — 検索結果・順位表・ペアリング・参加者一覧は高密度(表)、トップ・大会案内・公開デッキはカード型でゆったり |
| 着手順 | ①共通基盤(トークン+共通部品) → ②ポータルトップ → 以降はユーザーと相談 |

## 2. デザイントークン(`src/index.css` の `:root` に定義)

**このブロックが唯一のテーマ差し替えポイント。** コンポーネントCSSは必ず変数を参照し、
生のカラーコードを書かない(書いてよいのはこのブロックだけ)。

```css
:root {
  /* ベース(紙面) */
  --gw-bg: #f4f6f3;             /* ページ背景(わずかに緑がかったオフホワイト) */
  --gw-surface: #ffffff;        /* カード・パネル・ヘッダー面 */
  --gw-border: #dfe5dd;         /* 標準の枠線 */
  --gw-border-strong: #c5cec5;  /* ホバー時・強調枠線 */
  --gw-text: #26302a;           /* 本文 */
  --gw-text-muted: #67716a;     /* 補足・ラベル・メタ情報 */

  /* ブランド(テーマの核。差し替えるのは主にここ) */
  --gw-primary: #3f5c4b;        /* ジオングリーン: ボタン・リンク・アクティブ */
  --gw-primary-strong: #2e463a; /* hover/active・soft上の文字色 */
  --gw-primary-soft: #e9f0e9;   /* 選択背景・行ハイライト・バッジ地 */
  --gw-on-primary: #ffffff;     /* primary塗りの上の文字 */
  --gw-accent: #c23a5e;         /* モノアイピンク: 進行中・選択下線(2用途限定) */
  --gw-accent-soft: #f9e9ee;    /* accentバッジ地 */

  /* 状態 */
  --gw-danger: #b3352e;         /* 削除・中止・エラー */
  --gw-danger-soft: #f9ebea;

  /* 形状・奥行き */
  --gw-radius: 8px;             /* カード */
  --gw-radius-sm: 6px;          /* ボタン・入力・バッジ */
  --gw-shadow-card: 0 1px 2px rgba(38, 48, 42, 0.06);

  /* 余白スケール(マージン・パディングはこの6段から選ぶ) */
  --gw-space-1: 4px;  --gw-space-2: 8px;  --gw-space-3: 12px;
  --gw-space-4: 16px; --gw-space-5: 24px; --gw-space-6: 32px;

  /* タイポグラフィ */
  --gw-font: "Hiragino Kaku Gothic ProN", "Yu Gothic UI", "Noto Sans JP",
             system-ui, sans-serif;
}
```

- 将来のテーマ例(参考): 連邦ブルーなら primary系を `#2b4a78 / #1e3557 / #e8eef7`、
  accent を `#c8a13a` 等に差し替えるだけ。コンポーネント側は無変更。
- ダークモードは今回のスコープ外(SITE_DESIGN の将来課題に準ずる)。

## 3. アクセント(モノアイピンク)の使用制限

安っぽくならないよう **accent の用途は次の2つに限定**する:

1. ステータス「進行中」のバッジ・インジケータ
2. アクティブなナビ/タブの下線

ボタン・リンク・見出しには使わない(それらは primary)。

## 4. 共通コンポーネント規約

既存のバラバラなボタン・バッジ類を以下に統一する(クラスは既存名を活かしつつ
スタイルをトークン参照に置換。新規クラスを作る場合は `gw-` プレフィクス)。

- **ボタン**(高さ36px、radius-sm、文字13.5px):
  - primary: `--gw-primary` 塗り+白字。hover で `--gw-primary-strong`。1画面に主ボタンは原則1つ
  - secondary: 白地+ `--gw-primary` 枠と文字。hover で `--gw-primary-soft` 地
  - danger: 削除・中止のみ。`--gw-danger` 系
- **ステータスバッジ**(soft地+濃色文字、radius-sm、11〜12px):
  - 受付中= primary-soft/primary-strong、進行中= accent-soft/accent、
    完了=グレー(#ededea/#5f5e5a)、中止= danger-soft/danger、下書き=グレー枠のみ
  - 大会ステータスラベルは3ページに重複定義があるため `src/data/statusLabels.js` に集約する
- **カード**: surface 地+border+radius+shadow-card。hover で border-strong。
  リンクカードは全面クリック可能に
- **テーブル(高密度エリア)**: ヘッダは muted 12px、行 hover は primary-soft の半透明、
  順位表の1位行は primary-soft 地+primary-strong 文字
- **フォーム部品**: 枠線 `--gw-border`、フォーカスで `--gw-primary` の2pxリング。
  検索フォームの薄緑背景(#ebffe3)は `--gw-primary-soft` へ置換
- **フォーカス可視化**: すべての操作要素に `:focus-visible` のリングを付ける

| ページ | 密度 | 備考 |

| ポータルトップ | カード型 | サイトの顔。D2で本格リデザイン |
| 大会一覧・公開デッキ一覧 | カード型 | |
