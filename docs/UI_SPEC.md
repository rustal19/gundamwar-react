# UI定義書(v2 — 2026-07-05 ユーザー確定)

ヘッダー・各ページの表示物とUIの定義。見た目のトークン・部品規約は
[DESIGN_SPEC.md](DESIGN_SPEC.md)。本書と実装が食い違ったら本書が正。

> v1 からの変更: **ヘッダー廃止 → 左サイドバー常設**、タグライン廃止、
> トップは Wisdom Guild 風の「道具箱」スタイル、大会カード拡大+**開催地(venue)追加**。
> 承認済みモックは会話 2026-07-05 の `workbench_top_larger_tournament_area` が正。

## 0. 決定事項

| 項目 | 決定 |
|---|---|
| サイト名 | **Gundam War Portal**(全箇所の「Gundam War Database」を置換。App.test.js も更新) |
| ナビゲーション | **左サイドバー常設**(PC)。従来のヘッダーは廃止。モバイルはドロワー化 |
| トップ | ヒーロー・タグライン・導線カード廃止。**検索ボックス+大会+新着デッキの道具箱型** |
| 大会データ | **venue(開催地)フィールドを追加**(PORTAL_SPEC §2 反映済み。自由記述) |
| 検索結果 | カード型維持+「詳細/画像のみ」切替を /search に追加 |
| 密度 | 大会カードはゆったり2行、デッキ等のリストは罫線区切りの高密度行 |

## 1. サイドバー(全ページ共通)

### PC(幅 >1100px)
- 幅 200px 固定・左端・全高。背景 `--gw-surface`、右に罫線
- 上から:
  1. **ブランド**「Gundam War Portal」(クリックで `/`)
  2. **ナビ**(この順): ホーム(/) / カード検索(/search) / デッキ構築(/deck) /
     公開デッキ(/decks) / 大会(/tournaments)
     - 各項目: アイコン+ラベル。アクティブ= `--gw-primary-soft` 地+ `--gw-primary-strong` 文字

### アイコン(確定)

- 実装方式: **npm依存を追加しない**。Tabler Icons(MITライセンス、outline系)の SVG パスを
  `src/components/icons.js` にインラインReact部品として収録(冒頭コメントに出典とライセンスを明記)。
  サイズは 20px(縮小時 22px)、`stroke="currentColor"` で色は文字色に追従
- 割り当て:
  | 項目 | Tabler名 |
  |---|---|
  | ホーム | home |
  | カード検索 | search |
  | デッキ構築 | stack-2 |
  | 公開デッキ | cards |
  | 大会 | trophy |
  | 大会を作成 | circle-plus |
  | 権限管理 | user-cog |
  | プロフィール | user |
  | ログイン / ログアウト | login-2 / logout |
- **縮小時(56px)**: アイコンのみ表示。各項目に `title` とスクリーンリーダー用の
  非表示ラベルを付け、ホバーでツールチップ(title)が出ること
  3. (下部・罫線区切り)**運営メニュー** — organizer/admin のログイン時のみ表示。
     一般ユーザー(user)・未ログインには**見出しごと非表示**:
     - セクション見出し「運営メニュー」(10.5px・muted)
     - 大会を作成(/tournaments/new)— organizer/admin
     - 権限管理(/admin/users)— admin のみ
     - (初回のサイドバーモック `sidebar_workbench_layout_proposal` の構成が正)
  4. **ユーザー欄**(最下部): ログイン済み=イニシャル丸+ニックネーム。
     クリックでメニュー(プロフィール / ログアウト)。未ログイン=「ログイン」ボタン1つ
- `/deck`(デッキ構築)と `/search`(検索)では**アイコンだけの細い幅(56px)に自動縮小**
  (作業領域を確保。ホバーかクリックで一時展開)。それ以外のページは 200px 固定

### モバイル(compact ≤1100px)
- 上部スリムバー: ブランド+ハンバーガー(既存パターン)
- ドロワー: サイドバーと同内容(ナビ→ロール別→ユーザー欄)。ページ遷移で自動クローズ
- 全リンクは `buildPathWithForcedMobileLayout` でクエリ引き継ぎ(既存ルール)

### フッター(実装済み・変更点のみ)
- 左に「Gundam War Portal」表記を追加

## 2. トップ `/`(道具箱スタイル)

上から:
0. **あなたの大会**(ログイン時・エントリー中の大会がある場合のみ):
   検索ボックスの上に、自分がエントリー中(受付中・進行中)の大会を優先表示
   (§2 の大会カード+自分の状態。未提出警告もここに出る)
1. **カード名検索ボックス**(ページ最上部・幅いっぱい)
   - placeholder「カード名で検索」。Enter/検索ボタンで `/search?<カード名パラメータ>=入力値`
     (パラメータ名は SearchForm の name 条件と同一キー。実装時に確認)
2. **大会**(最大5件、開始日時昇順、「一覧へ」→ /tournaments)
   - **大会カード**(承認済みモックの構成):
     - 左: 日付ブロック(「7月/12/(土)」の3段、右罫線)
     - 中1行目: タイトル(15px・500)+ステータスバッジ
     - 中2行目: メタ4点(アイコン付き12px muted): 時刻 / 📍開催地(venue) /
       フォーマット(進行方式+レギュレーション名。例「スイスドロー・スタンダード」)/ 参加 n / 定員
     - 右: 状況ボタン — 受付中=「詳細」(primary)、進行中=「観戦」(secondary、
       詳細ページのペアリングタブへ)、それ以外=「詳細」(secondary)
3. **新着公開デッキ**(最大5件、「一覧へ」→ /decks)
   - 高密度行(罫線区切り): **色ドット**+タイトル+投稿者+公開日
   - 色ドットはデッキ内カードの色から導出(色情報フィールドは SearchResultCard の
     実装を参照。ユーティリティ `getDeckColors(items)` を utils に新設)
- 導線カードは廃止(サイドバーが導線を担う)

## 3. ページ別定義

### 3.1 検索 `/search`
- SearchForm+結果。条件なし時は案内表示(実装済み)
- 結果ツールバー: 件数・ページャ・**表示切替[詳細|画像のみ]を新設**(デッキ構築内の
  実装を流用。画像クリックで拡大=既存 CardImagePreviewDialog)・「デッキ」ボタン
- 「Loading...」→「読み込み中...」

### 3.2 公開デッキ一覧 `/decks`
- 検索ボックス(デッキ名・説明・ユーザー名)+**フォーマット絞り込み**(セレクタ)+ページャ
- **高密度行リスト**(トップと同形式): 色ドット+タイトル+**フォーマット**+説明1行+投稿者+枚数+公開日
- 右上「デッキ作成」→ /deck

### 公開操作(DeckLoadDialog 内の公開パネル)
- **公開時にフォーマットを必須選択**(セレクタ。選択肢は src/data/formats.js の
  FORMAT_PRESETS の name+「その他」。未選択では公開ボタン無効)
- フォーマット適合チェックは行わない(ラベルとしての選択。検証は大会提出時のみ)

### 3.3 公開デッキ詳細 `/decks/:id`
- ヘッダ: タイトル/色ドット/**フォーマットバッジ**/投稿者/公開日+**枚数サマリ**
  (例「メイン50・サイド10」。サイド0枚のデッキは「メイン50」のみ表示)
- アクション: このデッキをコピー(primary)/ 非公開にする(adminのみ・danger)/ 一覧へ
- 本文: 説明 → メイン(種別グルーピング・2列)→ サイド → **デッキ画像セクション**
- **カード名のマウスオーバーで画像プレビュー**(PC): カード行にホバーすると
  カード画像のポップオーバーを表示(共通部品 `CardHoverPreview` を新設。
  カーソル追従は不要、行の脇に固定表示で可)。モバイルはタップで既存の
  CardImagePreviewDialog(拡大ダイアログ)を開く
  - 同じ部品を**大会のデッキリスト表示**(参加者タブ・管理画面のデッキ閲覧)にも適用
- **デッキ画像セクション**(ページ下部): **既存の `useDeckPreview` フック
  (src/hooks/useDeckPreview.js。デッキ構築の書き出しダイアログが使用)で生成した
  デッキ画像をそのまま表示**する。新規のタイル実装はしない。
  生成中は「読み込み中...」、クリックで原寸表示

### 3.4 デッキ構築 `/deck`
- 現状レイアウト踏襲(PC=2ペイン+縮小サイドバー、モバイル=タブ)。トークン統一のみ

### 3.5 大会一覧 `/tournaments`
- statusフィルタ+ページャ
- **§2 の大会カードと同一コンポーネント**を使用(開催地・フォーマット込み)
- organizer/admin には「大会を作成」ボタン(サイドバーにもあるが一覧にも置く)

### 3.6 大会詳細 `/tournaments/:id`

> **ページ全体の承認済みモック**: `tournament_detail_full_layout`(2026-07-08)。
> 構成順: ヘッダ → アナウンス帯 → マイステータス帯(+対戦履歴) → タブ。
> ペアリングでは**自分の卓の行を soft 地でハイライト**し「あなた」と表記する。

- ヘッダ: タイトル+バッジ+主催者(公開プロフィールへリンク)+**開催地**+開始日時+定員。
  右上に**「URLをコピー」ボタン(全閲覧者向け)**。organizer 本人には「管理画面へ」も表示
- **マイステータス帯(エントリー済み参加者向け・フェーズ連動)** — タブの上に常設:
  | フェーズ | 判定条件 | 表示内容 |
  |---|---|---|
  | 開始前 | status=registration かつ 開催日(startsAt の日付)より前 | エントリー済み表示・デッキ提出状況・「提出し直す」「取消」(現行機能) |
  | 当日 | 開催日当日 かつ ラウンド未生成 | 自分のチェックイン状況。未=accent 帯「会場受付でチェックインしてください」/済=soft 帯「ペアリング発表までお待ちください」 |
  | ラウンド進行中 | **ラウンドが1つ以上生成された時点**(=チェックイン締切とみなす。締切時刻フィールドは追加しない) | **自分の卓番号(大きく)+現在ラウンド+対戦相手**(bye なら「不戦勝」)。結果登録済みならバッジで「結果: 勝利/敗北/引き分け」。未登録なら「結果は主催者が登録します」。ラウンド完了〜次生成の間は「次のペアリング待ち」 |
  - 未エントラント(ログイン済み・受付中)は従来どおりエントリー+デッキ提出フォーム
  - 承認済みモック: `participant_status_band_three_phases`(2026-07-05)
- **デッキ提出フロー(2026-07-08 明確化)**:
  - エントリーは**デッキなしでも可**(decklistRequired 大会でも)。提出締切は
    registrationClosesAt
  - 提出UI: マイステータス帯の「デッキを提出」→ ダイアログで
    ①保存デッキから選択(一覧+内容プレビュー) ②現在のデッキビルダーの内容
    ③「デッキ構築へ」リンク の3択。締切まで何度でも差し替え可。違反は一覧表示して
    提出ブロック(実装済み)
  - **未提出警告**: decklistRequired 大会で未提出の間、マイステータス帯を warning 表示
    「デッキリスト未提出 — 締切 7/12 18:00」。マイページの参加大会一覧にも「未提出」バッジ
- **チェックインフロー(明確化)**:
  - **会場開催**(isOnline = false): 会場受付で主催者が行う(参加者が名乗る →
    主催者が管理画面で操作 → 参加者の帯が「チェックイン済み」に変わる)
  - **セルフチェックイン許可時**(selfCheckin = true): 当日フェーズのマイステータス帯に
    「チェックインする」ボタン(primary)を表示。押すと即チェックイン済みに。
    開催日当日・ラウンド生成前のみ有効。主催者側からの操作も従来どおり併用可
  - selfCheckin は主催者が大会ごとに設定(オンライン/会場を問わず選択可)
- **自分の対戦履歴**: マイステータス帯に「対戦履歴」開閉 — 自分の全ラウンドの
  卓番号・対戦相手・結果を一覧表示
- **進行中の自動更新**: status = in_progress の大会詳細を開いている間、**30秒ごとに
  自動再取得**(ペアリング発表・結果反映にリロード不要。タブ非表示中は停止し、
  再表示時に即時更新)
- エントリー枠の機能(実装済み): エントリー/取消/デッキ提出(違反表示)/自主ドロップ
- **タブ5つの定義**(2026-07-08 改訂: 概要 / 参加者 / ペアリング / リザルト / 順位表):
  - **ラウンドの切替は共通のサブタブ**(「第1回戦 | 第2回戦 | …」。既定=最新)。
    アコーディオン(開閉式)は使わない
  - **概要**: 説明+開催地+レギュレーション詳細
  - **参加者**: ニックネーム+状態。**終了後、`decklistsPublic` が true の場合のみ**
    各行にデッキリストへのリンクを表示(false なら非公開のまま)
  - **ペアリング**: ラウンドごとの卓一覧を**卓番号の昇順**で表示。
    **結果は表示しない**(会場掲示のペアリングと同じ「卓・対戦者」のみ)。
    自分の卓は soft 地ハイライト+「あなた」表記。
    シングルエリミ形式および swiss のトップカット部分は
    **トーナメント表(ブラケット図)で表示**(承認済みモック `single_elim_bracket_mock`。
    ブラケットの勝敗表示はリザルト公開ルールに従い、終了前は勝ち上がりのみ表示)
  - **リザルト**(新設・ペアリングと順位表の間): ラウンドごとの結果一覧
    (卓番号昇順・対戦者・結果)。**大会が completed になるまでタブ自体を表示しない**
    (主催者・admin は管理画面で運営中も結果を確認できる)
  - **順位表**: 高密度テーブル・1位ハイライト。ラウンドのサブタブで
    各ラウンド終了時点の順位を閲覧できる(そのラウンドまでの対戦結果で再計算)
  - モック `tournament_detail_full_layout` のうち、ペアリングの結果バッジと
    過去ラウンドのアコーディオン表現は**本節の記述で上書き**(本文が正)

### 3.7 大会管理 `/tournaments/new`・`/tournaments/:id/manage`(2026-07-08 全面拡張)

セクション順: ガイド行 → 大会情報 → コミュニケーション → 参加者 → ラウンド運営 → 順位表 → 出力

**(a) ガイド行**: status 連動の「次にやること」(既存 U3)

**(b) 大会情報フォーム**
- 追加項目: 開催地(任意)/**「オンライン大会」チェック**(isOnline。venue 未入力時は
  「オンライン」と表示)/**「セルフチェックインを許可」トグル**(selfCheckin。独立した設定。
  isOnline をオンにした瞬間の既定値は true、以後は主催者が自由に変更)/
  「終了後にデッキリストを公開」トグル(decklistsPublic)/
  フォーマットプリセット選択(formats.js)/ ラウンド制限時間(分・任意 = roundTimeMinutes)
- **編集制約**: format・swissRounds(固定回戦数)・topCutSize(SE進出人数)は
  **ラウンド生成後は変更不可**(入力を無効化+理由をツールチップ表示)。他はいつでも変更可
- **レギュレーション編集**(禁止・制限カードの追加/解除含む)は運営中も可。
  変更保存時に提出済み全デッキを再検証し、**新たに違反となった参加者を警告リスト表示**
  (自動失格にはしない。主催者が個別に対応)
- **大会の中止**: 「大会を中止する」ボタン(danger・confirm付き。status → cancelled。
  どの status からでも可、completed からは不可)。**削除**: draft のみ「下書きを削除」可
- **宣伝URL**: 「大会URLをコピー」ボタン(詳細ページのURLをクリップボードへ)

**(c) コミュニケーション**
- **アナウンス投稿**: テキストエリア+「掲示する」ボタン(announcement を更新。
  最新1件方式・上書き。空で保存=掲示取り下げ)。掲示中の内容をプレビュー表示

**(d) 参加者管理**
- 一覧列: 名前(ゲストは「ゲスト」バッジ付き)/ 状態バッジ / **デッキ提出状況列**
  (提出済み=日時、未提出=accent「未提出」)/ 操作(チェックイン・ドロップ・デッキ閲覧)
- **「未提出のみ表示」フィルタ**+提出サマリ(8/8 など)
- **当日参加の手動追加**: 「参加者を追加」ボタン → 名前入力(+任意でデッキリスト)で
  ゲスト登録(アカウント不要)。受付中〜進行中(ラウンド間)まで可

**(e) ラウンド運営**
- ラウンド生成(既存)+以下を追加:
  - **ペアリング編集**: 未完了ラウンドに「ペアリングを編集」→ 各卓の対戦者をセレクタで
    入れ替え・卓番号変更。保存時に全員がちょうど1卓に居ることを検証
  - **リペアリング**: 未完了ラウンドの「破棄して組み直す」(confirm付き。破棄→再生成)
  - **結果の訂正**: 完了済みラウンドにも「訂正」ボタン → 結果セレクタを再有効化。
    順位表は自動再計算。SE/トップカットで後続と矛盾する場合は警告
    「後続ラウンドを破棄してください」を表示
  - **タイマー**: roundTimeMinutes 設定時、「タイマー開始」ボタン+残り時間の
    カウントダウン表示(クライアント計算。0で「時間切れ」表示。音は鳴らさない)

**(f) 出力**
- **デッキリスト一括発行**: 全参加者のデッキリストをテキスト連結(utils/deckExport.js の
  buildDeckExport 流用。「氏名+リスト」区切り)でコピー/`.txt` ダウンロード
- **デッキ画像の取得**: 参加者のデッキ閲覧ダイアログに「画像を保存」(useDeckPreview 流用、
  PNG ダウンロード)
- **掲示用表示**: 「掲示用に開く」→ `/tournaments/:id/display`(§3.9)を新規タブで

### 3.8 マイページ `/profile`(2026-07-08 拡張)・権限管理 `/admin/users`・規約 `/terms` `/privacy`
- `/profile` を「ニックネーム設定のみ」から**マイページ**に拡張。上から:
  1. プロフィール(ニックネーム表示・変更 — 既存)
  2. **あなたの大会**: 参加予定 / 進行中 / 過去 のグループ分けリスト
     (大会カード簡略版+自分の状態バッジ+decklistRequired 未提出なら「未提出」警告バッジ)
  3. **戦績**: 通算サマリ(参加大会数・優勝数・通算 勝-敗-分)+大会ごとの最終順位一覧
     (completed の大会のみ。standings から計算)
- 権限管理・規約は現状構成維持+トークン統一。規約は `.legal-page`(最大幅720px・行間1.8)

### 3.8b 公開プロフィール `/users/:id`(新規)
- 誰でも閲覧可。表示: ニックネーム(Google名は出さない)/ 公開デッキ一覧(§3.2 と同形式)/
  戦績(completed 大会の最終順位一覧+通算サマリ)
- 導線: 公開デッキの投稿者名・大会の参加者名・順位表のプレイヤー名をこのページへのリンクにする
- 自分のページには「マイページで編集」リンク

### 3.9 掲示用表示 `/tournaments/:id/display`(新規ルート)
- 会場のモニター掲示・印刷向け。**サイドバー・フッターなし**の全画面表示
- 上部: 大会名+現在ラウンド+(タイマー稼働中は)大きな残り時間

### 3.10 参加者側への反映(§3.6 マイステータス帯に追加)
- **アナウンス**: announcement があれば詳細ページ上部(マイステータス帯の上)に
  掲示帯(soft地・メガホンアイコン)を全閲覧者に表示
- **タイマー**: ラウンド進行中フェーズの帯に残り時間カウントダウンを併記(稼働中のみ)
