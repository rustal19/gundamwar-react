ヘッダー・各ページの表示物とUIの定義。見た目のトークン・部品規約は
[DESIGN_SPEC.md](DESIGN_SPEC.md)。本書と実装が食い違ったら本書が正。

> v1 からの変更: **ヘッダー廃止 → 左サイドバー常設**、タグライン廃止、
> トップは Wisdom Guild 風の「道具箱」スタイル、大会カード拡大+**開催地(venue)追加**。
> 承認済みモックは会話 2026-07-05 の `workbench_top_larger_tournament_area` が正。

## 0. 決定事項

| 項目 | 決定 |
|---|---|
| サイト名 | **Gundam War Portal**(全箇所の「Gundam War Database」を置換。App.test.js も更新) |
| ナビゲーション | **左サイドバー常設**(PC)。従来のヘッダーは廃止。モバイルはドロワー化 |

## 1. サイドバー(全ページ共通)

### PC(幅 >1100px)
- 幅 200px 固定・左端・全高。背景 `--gw-surface`、右に罫線
- 上から:
  1. **ブランド**「Gundam War Portal」(クリックで `/`)
  2. **ナビ**(この順): ホーム(/) / カード検索(/search) / デッキ構築(/deck) /
     公開デッキ(/decks) / 大会(/tournaments)
     - 各項目: Tablerアイコン+ラベル。アクティブ= `--gw-primary-soft` 地+ `--gw-primary-strong` 文字
  3. (下部・罫線区切り)**ロール別メニュー**:
     - 大会を作成(/tournaments/new)— organizer/admin のみ
     - 権限管理(/admin/users)— admin のみ
  4. **ユーザー欄**(最下部): ログイン済み=イニシャル丸+ニックネーム。
     クリックでメニュー(プロフィール / ログアウト)。未ログイン=「ログイン」ボタン1つ
- `/deck`(デッキ構築)のみ**アイコンだけの細い幅(56px)に自動縮小**
  (2ペインの作業領域を確保。ホバーかクリックで一時展開)

### モバイル(compact ≤1100px)
- 上部スリムバー: ブランド+ハンバーガー(既存パターン)
- ドロワー: サイドバーと同内容(ナビ→ロール別→ユーザー欄)。ページ遷移で自動クローズ
- 全リンクは `buildPathWithForcedMobileLayout` でクエリ引き継ぎ(既存ルール)

### フッター(実装済み・変更点のみ)
- 左に「Gundam War Portal」表記を追加

## 2. トップ `/`(道具箱スタイル)

上から:
1. **カード名検索ボックス**(ページ最上部・幅いっぱい)
   - placeholder「カード名で検索」。Enter/検索ボタンで `/search?<カード名パラメータ>=入力値`
     (パラメータ名は SearchForm の name 条件と同一キー。実装時に確認)
2. **大会**(最大5件、開始日時昇順、「一覧へ」→ /tournaments)
   - **大会カード**(承認済みモックの構成):
     - 左: 日付ブロック(「7月/12/(土)」の3段、右罫線)
     - 中1行目: タイトル(15px・500)+ステータスバッジ
     - 中2行目: メタ4点(アイコン付き12px muted): 時刻 / 📍開催地(venue) /
       フォーマット(進行方式+レギュレーション名。例「スイスドロー・スタンダード」)/ 参加 n / 定員
     - 右: 状況ボタン — 受付中=「詳細」(primary)、進行中=「観戦」(secondary、
       詳細ページのペアリングタブへ)、それ以外=「詳細」(secondary)
3. **新着公開デッキ**(最大5件、「一覧へ」→ /decks)
   - 高密度行(罫線区切り): **色ドット**+タイトル+投稿者+公開日
   - 色ドットはデッキ内カードの色から導出(色情報フィールドは SearchResultCard の
     実装を参照。ユーティリティ `getDeckColors(items)` を utils に新設)
- 導線カードは廃止(サイドバーが導線を担う)

## 3. ページ別定義

### 3.1 検索 `/search`
- SearchForm+結果。条件なし時は案内表示(実装済み)
- 結果ツールバー: 件数・ページャ・**表示切替[詳細|画像のみ]を新設**(デッキ構築内の
  実装を流用。画像クリックで拡大=既存 CardImagePreviewDialog)・「デッキ」ボタン
- 「Loading...」→「読み込み中...」

### 3.2 公開デッキ一覧 `/decks`
- 検索ボックス(デッキ名・説明・ユーザー名)+ページャ
- **高密度行リスト**(トップと同形式): 色ドット+タイトル+説明1行+投稿者+枚数+公開日
- 右上「デッキ作成」→ /deck

### 3.3 公開デッキ詳細 `/decks/:id`
- ヘッダ: タイトル/色ドット/投稿者/公開日+**枚数サマリ**(例「メイン50・サイド10」)
- アクション: このデッキをコピー(primary)/ 非公開にする(adminのみ・danger)/ 一覧へ
- 本文: 説明 → メイン(種別グルーピング)→ サイド

### 3.4 デッキ構築 `/deck`
- 現状レイアウト踏襲(PC=2ペイン+縮小サイドバー、モバイル=タブ)。トークン統一のみ

### 3.5 大会一覧 `/tournaments`
- statusフィルタ+ページャ
- **§2 の大会カードと同一コンポーネント**を使用(開催地・フォーマット込み)
- organizer/admin には「大会を作成」ボタン(サイドバーにもあるが一覧にも置く)

### 3.6 大会詳細 `/tournaments/:id`
- ヘッダ: タイトル+バッジ+主催者+**開催地**+開始日時+定員。organizer本人には「管理画面へ」
- エントリー枠(実装済み): エントリー/取消/デッキ提出(違反表示)/自主ドロップ
- タブ: 概要(説明+開催地+レギュレーション詳細) / 参加者 / ペアリング / 順位表(高密度・1位ハイライト)

### 3.7 大会管理 `/tournaments/new`・`/tournaments/:id/manage`
- 大会情報フォームに**「開催地」入力欄を追加**(任意・テキスト)
- フォーマットプリセット選択を追加(src/data/formats.js。リスト受領後)
- 上部に status 連動の「次にやること」ガイド行
- セクション順は現状維持: 情報 → ステータス → 参加者 → ラウンド → 順位表

### 3.8 プロフィール `/profile`・権限管理 `/admin/users`・規約 `/terms` `/privacy`
- 現状構成維持+トークン統一。規約は `.legal-page`(最大幅720px・行間1.8)
